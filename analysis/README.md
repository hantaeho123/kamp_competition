# 제조 생산데이터 기반 전력사용량 예측 및 최대피크 위험조건 분석

제6회 K-인공지능 제조데이터 분석 경진대회 · 과제 ⑤ 자원 최적화 AI 데이터셋 · 소스코드 제출물

## 1. 구성

| 제출 요구 항목 | 위치 | 설명 |
|---|---|---|
| 소스코드 | `analysis.ipynb` | 전처리부터 학습·추론·분석·결과 생성까지 모든 코드와 설명, 실행 결과(표·그림)가 들어 있는 노트북 |
| 실행 환경 | `requirements.txt` | Python 3.11 기준 고정 버전 패키지 목록 |
| 학습용 데이터 | `data/okm_augumented_2021.csv` | KAMP 제공 원본(2021-01-01~09-14, 6,168행) |
| README | `README.md` | 이 문서 |
| 테스트데이터 예측결과 파일 | `predictions/` | 시험 구간(2021-09-01~14) 예측 결과 3개 파일 |
| (부가) 분석 결과 | `outputs/step0_…` ~ `step6_…` | 단계별 표(CSV)와 그림(PNG) |
| (부가) 탐색 기록 | `reference/tuning_trials.csv` | 하이퍼파라미터 탐색 85가지 시도의 기록 |

## 2. 실행 방법

```bash
python -m venv .venv && source .venv/bin/activate      # Python 3.11
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute --inplace analysis.ipynb
```
- Jupyter나 VS Code에서 `analysis.ipynb`를 열어 "모두 실행"해도 같습니다.
- 한 번 실행하면 데이터 전처리 → 모델 비교·학습 → 시험 구간 추론 → 오차·피크 분석 → 저감 시뮬레이션 → 결과 파일 생성까지 자동으로 진행됩니다.
- 실행 시간은 CPU 기준 약 15~25분입니다. 하이퍼파라미터 탐색(약 45분)은 기록된 최적 설정을 쓰므로 기본 실행에 포함되지 않으며, 노트북의 `RUN_SEARCH = True`로 다시 수행할 수 있습니다. 난수 시드(42), 스레드 수(4), 패키지 버전을 고정했습니다.
- 노트북은 자기 폴더를 기준으로 `data/`를 읽고 `predictions/`, `outputs/`에 씁니다. 다른 파일은 필요 없습니다.

## 3. 과제 정의

- **예측 대상:** 15분 단위 최대수요전력(원본 `15분/30분/45분/60분` 컬럼), 하루 96개
- **예측 시점:** 전날 24시에 다음 날 하루 전체를 예측(생산일정을 바꿀 수 있는 마지막 시점)
- **시험 구간:** 2021-09-01~14(1,342개 15분 슬롯). 모델 선택은 7~8월 8주 롤링 검증으로 하고 시험은 마지막에 한 번만 평가
- **피크 정의:** 15분 최대수요전력 180kW 이상(전체 슬롯의 상위 5%)

## 4. 분석 흐름(노트북 목차)

| 단계 | 내용 | 핵심 결과 |
|---|---|---|
| 0. 전처리·분할 | 결측·이상치 처리, 복사일 확인, 누수 변수 제거, 불균형 확인, 시간 순 분할 | 257일 중 160일이 1~6월 내부 복사일. 공장인원 = 생산량 ÷ 전력 합으로 계산된 누수 변수임을 밝혀 제거. 무작위 분할은 시험 표본 58%가 학습셋에 복사본 |
| 1. 전력 예측 | 베이스라인 2종 대 Ridge·RandomForest·MLP·ExtraTrees·부스팅 4종 비교, **하이퍼파라미터 85가지 탐색, 앙상블 5종 비교**, 일 최대 예측, 예측구간, **피크 발생 확률 모델** | 최종 ExtraTrees(검증 MAE 최저): 시험 MAE 6.47kW(CV(RMSE) 8.7%, 베이스라인 11.52kW). 일 최대 MAE 5.82kW, 피크 경보 F1 0.46(베이스라인 0.37~0.39) |
| 2. 예측오차 분석 | 피크 시간 대 전체, 시간대·생산조건·가동상태별, 놓친 피크·헛경보 | 전체 MAE 7.18kW 대 피크 시간 12.54kW |
| 3. 피크 추출 | 180kW 이상 연속 구간 | 426개(복사일을 한 번만 세면 267개) |
| 4. 피크 두 유형 | 상승폭·지속시간·직전 부하로 구분 | 시작·재개 직후 크게 오르는 피크 / 가동 중 잠깐 더 오르는 피크 |
| 5. 유형별 발생조건 | 시각, 생산량, 생산량 변화, 운영상태, 기온 | 유형별로 시각과 생산계획 변화가 뚜렷이 다름 |
| 6. 저감방안 | 유형별 조치 시뮬레이션, 예측 연동 운영 검증, 요금 환산 | 두 조치 동시 적용 시 일 최대 11.5kW(5.8%) 감소. 시험 2주 최대수요전력 204 → 189kW |
